### 踩坑 / 经验
- `gh api repos/x` 单次循环超过 ~20 个仓库会被沙箱 SIGTERM（exit 137），必须**分批（每批 20 个）**跑，并且不要用 `| jq` 二次管道（大 JSON 会触发 jq parse error），改用 `gh api --jq` 内置 jq。
- GitHub 搜索多词短语要用 URL encode 后走 `search/repositories` API，`gh search repos` 对空格分词较敏感，容易返回空结果。
- 高 star 仓库的星标与第三方榜单（skillselion / claudeskills.info 等）差异很大，必须以 GitHub API 为准。
